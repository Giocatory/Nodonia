# Тесты Нодонии

- `run_all.js` — запускает все наборы из `cases/` (чистый Node, без зависимостей). Каждый набор загружает нужные скрипты в изолированный `vm`-контекст через `load.js` и печатает `PASS`/`FAIL`.
- `cases/` — проверки протоколов (`proto_*`, `raft_basic`), движка, цепочки (`chain_*`), сетей PoW/PoS (`net_*`), архитектур (`arch_*`) и контента (`content_*`: каждое задание решается «как студент», у каждой лабораторной существуют шаблон и протокол, в банке вопросов нет дублей).
- `ui_smoke.js` — открывает в Chromium каждый раздел и собирает ошибки консоли: `NODE_PATH=… node ui_smoke.js [out.png] [ключ] [мс]`.
- `ui_practice.js`, `ui_shots.js`, `ui_shot.js` — сценарии для проверки раздела «Практика» и съёмки скриншотов.

Запуск: `node tests/run_all.js`. Смоук-тесту нужен Playwright (`npm i playwright`).
